# Getting started with Thiscovery Mapping

This page is for people who create and manage maps. Administrators enable the module, add a map key, and set permissions; you create the map, choose what people can draw, and share it.

## Where maps live

- **Network (global) maps** — created at site level under **Administration → Thiscovery Mapping**. Use these for maps that should not belong to a single space.
- **Space maps** — created inside a space. Members of that space are the usual audience.

You need **Create maps** / **Create global maps** to start a map, and **Manage maps** / **Manage global maps** to edit, moderate, and delete.

## The map list

The list is the home for maps. From here you can search by title, filter by visibility, **Open** a map, **Edit**, **Moderate** (when drawings need approval), or **Delete**.

**Configuration** is only on the network list, for people who can manage modules.

**Help** (this set of pages) is on the list for creators and administrators. People who only view or draw on a map do not see it.

## Create a map

1. Open **Thiscovery Mapping** (Administration, or **Maps** in the space menu).
2. Choose **Create map**.
3. Enter a **Title**. Everything else can stay at the defaults until you need it.
4. Save. You land on the live map. Use **Edit** to change settings, or **Back to maps** to return to the list.

New maps inherit the site default centre, zoom, and basemap style from Configuration.

## Open, edit, and share

**Open** shows the map as people will use it: search a place, filter drawings, and (if they have permission) add pins, lines, or areas.

**Edit** is the settings form: title, starting view, drawing types, visibility, categories, extra questions, and background layers.

The map page URL can be shared. You can also embed the map on a Thiscovery page or add a map question to a Thiscovery Form.
