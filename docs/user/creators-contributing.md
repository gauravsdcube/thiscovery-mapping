# Contributions and moderation

This page is for how people add drawings, who can see them, and how you review and export them.

## Who can draw

People need **Contribute to maps** (space) or **Contribute to global maps** (network). Map managers can always edit the map itself. Guests cannot draw.

On the map, people with permission get drawing tools for the types you allowed: pins, lines, and areas. After they draw, a panel opens for an optional comment, a category if you set those, and any extra questions. Choice questions show as tappable options. Place search is available only if you enabled it on Edit map.

## Exploring the map

Anyone who can view the map can:

- Pan and zoom
- Search for a place, postcode, or address — only if **Show place search** is on for that map
- Filter by category, drawing type, and date — only if **Show filters** is on for that map
- Open a drawing for details, likes, and comments
- Use clusters to work through overlapping pins

Filters do not change who is allowed to see a drawing. **Own only** and **Moderated** still apply.

## Visibility

Set this on **Edit map**. It controls which drawings appear, not who can open the map page.

- **Everyone** — all approved (or unmoderated) drawings are visible to people who can view the map.
- **Own only** — each signed-in person sees only their own drawings. Useful for private reflections.
- **Moderated** — new drawings stay **Pending** until a map manager approves or rejects them. Pending items show on the list and on **Moderate**.

## Moderate

When visibility is **Moderated**, **Moderate** appears on the map list and on the map page for managers.

Open the queue, read the comment, then **Approve** or **Reject**. Approved drawings appear on the map. **Back to maps** returns to the list; **Back to map** returns to the live map.

## Export

Managers can download **GeoJSON** (for GIS tools) or **CSV** (for spreadsheets) from the map page. Exports include approved contributions. Use this for analysis or to archive a consultation.

## Delete

Deleting a map from the list removes the map and all contributions. That cannot be undone.
