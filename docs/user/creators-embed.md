# Pages, forms, and the top bar

This page is for putting a map in front of people: on a Thiscovery page, as a form question, or in the site menu.

## Embed on a Thiscovery page

If **Thiscovery Page Builder** is enabled, the studio palette includes a **Map** block (under Engagement).

1. Edit a page in Page Builder.
2. Add a **Map** block.
3. Choose the map. You can pick a network map or a map from a space, if you can view it.
4. Set the height if you need a taller or shorter canvas.
5. Save and publish the page.

Visitors use the embedded map the same way as the map page: pan, zoom, filter, and draw if they have permission. If Mapping is turned off, Page Builder shows that the map block is unavailable instead of adding it.

## Map question on a Thiscovery Form

If **Thiscovery Forms** is enabled, a form can include a **map** question. Respondents draw on a small map as their answer (usually a pin). Place search and the starting view follow Mapping configuration.

Mapping must stay enabled for people to answer map questions. Existing map questions are kept if Mapping is later turned off; new map questions cannot be added until it is on again.

Use a form map question when the drawing is one answer among others. Use a full map (this module) when people should explore many contributions together.

## Top bar and Navigation

When **Thiscovery Navigation** is enabled, do not add map links from this module. Add them in **Administration → Thiscovery Navigation** so the top bar stays in one place.

If Navigation is not enabled, a **Maps** item can appear in the top bar when there is at least one network map.

Space maps appear in that space’s **Maps** menu when the module is enabled on the space.
